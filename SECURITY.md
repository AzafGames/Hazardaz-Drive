# 🔐 Security Policy

## Hazardaz-Drive

Thank you for helping keep **Hazardaz-Drive** safe and reliable.

**Hazardaz-Drive** is a Unity-based arcade driving game developed using **Unity 6.3 LTS and C#**.

Security issues, vulnerabilities, and other potentially harmful problems are welcome for responsible reporting.

---

## 📌 Supported Versions

Hazardaz-Drive **currently has no officially supported versions or releases**.

The project is actively under development, and security-related issues will be reviewed based on their severity and impact.

---

## 🚨 Reporting a Security Problem

Please report security problems **directly to the project maintainer** rather than publicly posting sensitive details.

When submitting a report, provide as much relevant information as possible so the issue can be properly investigated.

### Please include:

* **Issue title**
* **Detailed description of the problem**
* **Steps to reproduce**
* **Expected behavior**
* **Actual behavior**
* **Affected Unity version or project version**
* **Affected platform**
* **Affected file, script, system, or component**
* **Error messages or logs**
* **Screenshots or screen recordings**
* **Proof of concept**, when applicable
* **Potential impact**
* **Suggested fix**, if you have one

Providing complete and accurate information helps make investigation and resolution faster.

---

## 🔒 Do Not Publicly Share Sensitive Information

Please do not include the following in public issues, discussions, commits, or other public channels:

* Passwords
* API keys
* Authentication tokens
* Private credentials
* Private keys
* Personal information
* Sensitive configuration data
* Any other confidential information

---

## 🛡️ Responsible Disclosure

When reporting a security vulnerability:

* Do not intentionally damage the project or infrastructure.
* Do not access or modify data that does not belong to you.
* Do not disrupt services or development systems.
* Do not use vulnerabilities for malicious purposes.
* Provide enough technical information to reproduce and understand the problem.

Please allow the maintainer reasonable time to investigate the reported issue before publicly disclosing detailed technical information.

---

## 🧩 Third-Party Components

Hazardaz-Drive may use third-party:

* Unity packages
* Assets
* Models
* Textures
* Audio
* Plugins
* Libraries
* Development tools

Problems originating from third-party components may also be reported, especially when they could affect the security or integrity of the project.

---

## 🐛 General Bugs and Development Issues

Normal gameplay bugs, visual problems, feature requests, performance issues, and development suggestions do **not** need to be reported as security vulnerabilities.

These can be submitted through the repository's normal **GitHub Issues** system.

For any reported problem, please provide **clear reproduction steps and relevant technical details**.
